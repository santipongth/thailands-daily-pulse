# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, and assume good intent. Critique ideas, not people. No harassment, discrimination, personal attacks or doxxing, and that includes in Thai-language spaces.

Report problems privately to the maintainers through GitHub (Security → Report a vulnerability, or a direct message to a maintainer). Reports are handled confidentially. Maintainers may remove content or ban participants who violate this code.
