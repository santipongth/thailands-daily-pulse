# ปรับหน้าวันนี้: สัญญาณเฉพาะที่เกินเกณฑ์ + ออกแบบส่วนสถานีตรวจอากาศใหม่

## 1. สัญญาณวันนี้ — แสดงเฉพาะการ์ดที่เกินเกณฑ์

ตรวจสอบแล้ว: หน้าวันนี้แสดงเฉพาะสัญญาณที่เกินเกณฑ์อยู่แล้ว ระบบตรวจจับเก็บเฉพาะสัญญาณที่ผ่านเกณฑ์เท่านั้น (ส่วนย่อย "ใกล้เกณฑ์/เล็กน้อย" ถูกลบไปก่อนหน้าและยืนยันว่าไม่มีในโค้ด) — ไม่มีการเปลี่ยนแปลงในส่วนนี้

## 2. สถานีตรวจอากาศใกล้กรุงเทพฯ — ออกแบบใหม่

เปลี่ยนจากรายการสองคอลัมน์ที่อ่านยาก เป็น **ตารางแบบหนังสือพิมพ์** ที่อ่านเปรียบเทียบกันได้ทันที:

- คงส่วนหัวเดิม (หัวข้อแดง + เส้นบาง + บันทึกสีเทา + ลิงก์ "ดูทุกสถานี →")
- เนื้อหาเป็นตาราง 5 แถว (1 สถานีต่อแถว) คั่นด้วยเส้นบาง:
  - **คอลัมน์ซ้าย:** ชื่อสถานี (ตัวหนา) + ระยะห่างจากใจกลางกรุงเทพฯ (ตัวเล็กสีเทา เช่น "9 กม.")
  - **คอลัมน์กลาง:** อุณหภูมิ ตัวเลขใหญ่แบบเซอริฟ เช่น "32.7°C"
  - **คอลัมน์ขวา:** ฝน 24 ชม. (มม.) — ถ้ามีฝน (>0 มม.) แสดงตัวหนาสีแดงเพื่อให้เห็นทันที ถ้าไม่มีฝนแสดงสีเทา
  - **ใต้ชื่อสถานี:** เวลารายงานล่าสุด (เช่น "รายงาน 3 ต.ค. 22:00 น.")
- แถวที่ร้อนที่สุดอยู่บนสุด (เรียงตามอุณหภูมิ) พร้อมป้ายเล็ก ๆ "ร้อนสุด" ที่แถวแรก
- ลบเวลา "รับ ..." ออกจากทุกแถว (ข้อมูลประกอบ ไม่จำเป็นต่อผู้อ่าน)
- บนมือถือ: แต่ละแถวยังอ่านง่าย ตัวเลขไม่ล้นขอบ

ข้อมูลที่ใช้เหมือนเดิมทุกประการ (กรมอุตุนิยมวิทยา ราย 3 ชม.) ไม่แตะต้องการดึงข้อมูลหรือเกณฑ์ใด ๆ
