# ซ่อนการ์ด "เล็กน้อย", หน้าติดตามข้อมูลที่ยังไม่เปลี่ยน, ตั้งเวลาดึงเองทุกแหล่ง

## 1. หน้า "วันนี้" แสดงเฉพาะ "น่าจับตา" และ "สำคัญมาก"
- ตรวจแล้ว: ช่วง 7 วันมีสัญญาณระดับเล็กน้อย 3 รายการที่ยังโผล่ในหน้าวันนี้
- กรองให้เหลือเฉพาะระดับน่าจับตา/สำคัญมาก ทั้งในรายการการ์ด ตัวนับ "พบ N สัญญาณ" และข้อความสรุปด้านบน
- สัญญาณเล็กน้อยยังเก็บในระบบและดูได้ในหน้าประวัติ/รายหมวด (ไม่ลบข้อมูล ไม่เปลี่ยนเกณฑ์)

## 2. หน้าใหม่ "ข้อมูลที่ยังไม่เปลี่ยน" (/unchanged)
- รายการตัวชี้วัดที่ค่าล่าสุดเท่ากับค่าเดิม เรียงจากนิ่งนานที่สุด เช่น ก๊าซหุงต้ม 423 บาท (มีผลตั้งแต่ 1 มี.ค. 2566)
- แต่ละแถว: ชื่อ, ค่าปัจจุบัน, วันที่มีผล, นิ่งมาแล้วกี่วัน, ตรวจล่าสุดเมื่อไร, แหล่งที่มา
- แยกให้ชัด 3 สถานะ: "ตรวจแล้ว ค่าไม่เปลี่ยน" / "แหล่งไม่อัปเดต (ข้อมูลเก่า)" / "ตรวจไม่ได้" — ไม่นับว่าไม่เปลี่ยนเมื่อดึงไม่สำเร็จ
- ลิงก์จากเมนูหลักและท้ายส่วน "สัญญาณวันนี้"; หน้าสาธารณะ อ่านอย่างเดียว

## 3. ตั้งเวลาดึงเองทุกแหล่งในหน้า admin
- ตัวจัดการแหล่งข้อมูลมีตัวเลือกช่วงเวลาอยู่แล้ว (ค่าเริ่มต้น/รายชั่วโมง/3 ชม./รายวัน/ช่วงเวลา/ด้วยมือ + รอบเพิ่ม) จะเพิ่ม:
  - โหมดใหม่ "กำหนดเวลาเอง": เลือกหลายเวลาได้ (ชั่วโมง:นาที เช่น 05:10, 12:30, 18:00)
  - แสดง "รอบถัดไป" ของแต่ละแหล่งให้เห็นทันทีหลังบันทึก
  - ใช้ได้กับทุกแหล่ง รวมแหล่งที่ใช้ AI อ่านหน้าเว็บ (ก๊าซหุงต้ม) และแหล่งผ่าน X (FM91/BTS/MRT) — แอดมินกำหนดเวลาเอง ไม่ต้องพึ่งรอบอัตโนมัติ
- เวลาตัดรอบและเผยแพร่ฉบับเช้า (05:45/05:55) ไม่เปลี่ยน

## Technical details
- `index.tsx`: `moves = signals.filter(s => !s.is_demo && s.severity !== 'low')`; ใช้ชุดเดียวกันใน activeFams/fallback.
- `/unchanged`: loader อ่าน observations ล่าสุด 2 ค่าที่ต่างวันต่อ metric + `source_runs`/completeness; คำนวณ "นิ่งตั้งแต่" = วันแรกของค่าปัจจุบันแบบต่อเนื่อง หรือ `effective_from`. ผ่าน anon RLS เท่านั้น. head() ครบ.
- Migration: `source_config.custom_times text[]` (HH:MM, Asia/Bangkok) + schedule `custom`; ตรวจใน `applySourceConfig` (ตรงนาทีในหน้าต่าง cron ที่รันอยู่ ±รอบ tick) — ถ้า tick ปัจจุบันหยาบกว่า 10 นาที จะเพิ่ม pg_cron tick ทุก 5 นาทีที่เรียกเฉพาะแหล่ง custom; zod validate ใน `requireAdmin` fn; ฟังก์ชัน `nextRun(cfg)` ใช้ทั้ง UI และ server.
- อัปเดต AGENTS.md (กฎ custom schedule) และ memory (ไม่แสดงระดับเล็กน้อยบนหน้าวันนี้).
