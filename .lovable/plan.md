# Thailand Daily Signals

หน้าเดียวตอบคำถาม: "วันนี้มีอะไรเปลี่ยนไปในประเทศไทยที่อาจกระทบชีวิตฉัน?"
หลักการ: **No change = no signal** อะไรไม่เปลี่ยนก็เงียบ อะไรเปลี่ยนอย่างมีนัยสำคัญถึงจะขึ้นเป็น Signal

## สิ่งที่ผู้ใช้จะเห็น

1. **Thailand Today — วันที่ (พ.ศ.)** สรุปสั้นๆ 3-5 บรรทัดที่ AI เขียนเป็นภาษาคน เช่น "ค่าครองชีพวันนี้สูงขึ้น หมูและน้ำมันขึ้นพร้อมกัน ถ้าใช้น้ำมัน 40 ลิตร/เดือน จ่ายเพิ่มราว 20 บาท"
2. **การ์ด Signal วันนี้** เฉพาะกลุ่มที่เปลี่ยนจริง เรียงตามความสำคัญ (สูง/กลาง/ต่ำ) แต่ละการ์ดมีค่าเดิม → ค่าใหม่, % เปลี่ยนแปลง, กราฟเล็ก 14 วัน, แหล่งที่มา, เวลาอัปเดต
3. **การประกาศสำคัญ** (GDP, CPI, ดอกเบี้ยนโยบาย, หวย ฯลฯ) จะโผล่เฉพาะวันที่มีตัวเลขใหม่ออก
4. **"เงียบวันนี้"** แถบเล็กๆ บอกว่ากลุ่มไหนไม่มีอะไรเปลี่ยน (กดดูค่าล่าสุดได้)
5. **ปฏิทินข้อมูลที่จะออก** เช่น "พรุ่งนี้ น้ำมันปรับราคา", "ศุกร์นี้ CPI เดือน ก.ย."
6. หน้ารายละเอียดของแต่ละกลุ่ม (ประวัติย้อนหลัง + ทุก Signal ที่เคยเกิด)

## กลุ่มข้อมูล (ครบทุกกลุ่มในตาราง)

|---|---|---|

| ราคาอาหาร/ตลาด/เกษตร (กรมการค้าภายใน, ตลาดไท) | รายวัน | ข้อมูลจำลองก่อน |

ทุกการ์ดมีป้าย "ข้อมูลจริง" หรือ "ข้อมูลตัวอย่าง" ชัดเจน กลุ่มจำลองจะเปลี่ยนเป็นจริงทีละกลุ่มภายหลัง

## กฎการเกิด Signal (ตัวอย่าง)

- ราคาน้ำมันเปลี่ยน ≥ 0.10 บาท หรือมีประกาศพรุ่งนี้
- ทองเปลี่ยน ≥ 100 บาท
- เงินบาทเปลี่ยน ≥ 0.5% จากเมื่อวาน
- PM2.5 ข้ามเกณฑ์ (37.5 / 75 µg/m³) หรือเปลี่ยนระดับสี
- ราคาอาหารหลักเปลี่ยน ≥ 3%
- ข้อมูลรายเดือน/ไตรมาส: ขึ้นเป็น Signal เฉพาะวันที่ออกตัวเลขใหม่
- มีคำเตือนภัยจากกรมอุตุฯ / กรมชล = Signal ระดับสูงเสมอ

## หน้าตา

โทนหนังสือพิมพ์เช้า: พื้นกระดาษสีครีม, ตัวอักษรไทยหัวข้อแบบมีหัว (เช่น Noto Serif Thai) + เนื้อหา IBM Plex Sans Thai, สีเน้นแดงอิฐสำหรับ "ขึ้น" และเขียวหม่นสำหรับ "ลง", ไม่มีภาพประกอบเยอะ เน้นตัวเลข อ่านง่ายบนมือถือ

## Technical details

- เปิด Lovable Cloud: ตาราง `sources`, `observations` (ค่าตามเวลา), `signals` (สิ่งที่ตรวจจับได้ + ระดับ), `daily_briefs` (สรุป AI ต่อวัน), `release_calendar` อ่านได้สาธารณะ เขียนได้เฉพาะงานเบื้องหลัง
- ตัวดึงข้อมูลแยกต่อแหล่ง (connector) อยู่ใต้ `/api/public/ingest/*` เรียกตามรอบด้วยตัวตั้งเวลา (pg_cron) ป้องกันด้วย secret token, มี lock กันรันซ้อน และจำกัดจำนวนงานต่อรอบ
- ตัวตรวจจับการเปลี่ยนแปลง: เปรียบเทียบค่าล่าสุดกับค่าก่อนหน้า/ค่าเฉลี่ย 7 วัน ตามกฎของแต่ละกลุ่ม แล้วบันทึก signal (ไม่ซ้ำด้วย unique key กลุ่ม+วัน+ตัวชี้วัด)
- สรุปประจำวัน: สร้างวันละครั้ง (และเมื่อมี signal ระดับสูงใหม่) ด้วย Lovable AI โดยส่งเฉพาะ signal ของวันนั้น เก็บผลไว้ในฐานข้อมูล หน้าเว็บไม่เรียก AI ตอนเปิด
- ข้อมูลจำลอง: ใส่ประวัติ 30 วันผ่าน migration เพื่อให้หน้าแรกมีของทันที
- หน้า: `/` (Thailand Today), `/signals/$family` (รายละเอียด), `/sources` (แหล่งข้อมูล + สถานะการอัปเดตล่าสุด)
- data.go.th (CKAN API) ใช้เป็น registry สำหรับเพิ่ม connector ใหม่ภายหลัง
- แหล่งที่ต้องขอ API key (เช่น ธปท., กรมอุตุฯ TMD API) จะขอผ่านช่องเก็บรหัสอย่างปลอดภัยเมื่อถึงขั้นตอนนั้น; ถ้ายังไม่มี key ใช้ข้อมูลจำลองไปก่อน
