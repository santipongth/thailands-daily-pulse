# ปรับปรุงการ์ด "สัญญาณวันนี้" และออกแบบ "ผลสลากงวดล่าสุด" ใหม่

ผู้ใช้เลือกแล้ว: ลบวันที่ทั้งหมดบนการ์ดสัญญาณ และเลือกแบบสลาก "หนังสือพิมพ์คลาสสิก" (prototype v1) — แก้เฉพาะการแสดงผล ไม่แตะข้อมูล ฐานข้อมูล หรือเกณฑ์สัญญาณ

## 1. การ์ด "สัญญาณวันนี้" — ลบวันที่ทั้งหมด + จัดระเบียบใหม่

### ลบรายการ "วันที่ข้อมูลเข้าจริง"
- `src/components/weekly-comparison.tsx`: ลบทั้งบล็อกรายการใต้กราฟ (หัวข้อ "วันที่ข้อมูลเข้าจริง" และบรรทัด "ข้อมูล X · มีผล Y · รับ Z") และลบฟิลด์ `arrivals` ออกจาก type `WeekSummary`
- ลบการป้อน `arrivals` ใน 3 ไฟล์ที่สร้างข้อมูลให้กราฟ: `metric-signal-chart.tsx`, `cost-signal-chart.tsx`, `rail-signal-chart.tsx`

### ลบบรรทัดวันที่บนหัวการ์ด
- `src/components/signals-ui.tsx`: ลบการเรียก `<SignalDates s={s} history={history} />` (บรรทัด "ข้อมูลวันที่ X · มีผล Y · ได้รับ Z" และป้าย "ข้อมูลมาช้า N วัน") ออกจากการ์ด และลบ component `SignalDates` ทิ้ง
- หมายเหตุ: ข้อมูลวันที่ยังเก็บในฐานข้อมูลครบตามเดิม (effective_from, received_at) — ลบเฉพาะการแสดงผล เกณฑ์และการตรวจจับสัญญาณไม่เปลี่ยน

### จัดระเบียบการ์ดใหม่
- ใน `weekly-comparison.tsx` จัดผังใหม่ให้อ่านง่าย: ค่า 2 ช่วงสัปดาห์วางเคียงกันชัดเจน (ค่าเก่าโทนเทา / ค่าใหม่โทนแดงตามสีแท่งกราฟ) แสดงค่า หน่วย และจำนวนวันที่มีข้อมูลของแต่ละช่วงแบบกระชับ ไม่มีรายการวันที่รกสายตา
- ทำให้การ์ดทุกชนิด (ราคา/ดัชนี/จราจร/รถไฟฟ้า) ใช้ผังเดียวกัน — กราฟแท่งเทียบ 2 สัปดาห์ ตามด้วยค่าสรุปสองคอลัมน์

## 2. หน้า "ผลสลากงวดล่าสุด" — ออกแบบใหม่แบบหนังสือพิมพ์คลาสสิก (v1)

แก้ `src/components/latest-lottery.tsx` คงใช้ `TodaySection` (หัวแดง + เส้นบาง + หมายเหตุเทา) แต่เปลี่ยนเนื้อหาเป็นผังสองคอลัมน์ (มือถือเรียงลง):

- **คอลัมน์ซ้าย (รางวัลที่ 1):** แถบป้ายแดง "รางวัลที่ 1" + งวดวันที่ด้านขวา, เลขรางวัลตัวใหญ่มากด้วยฟอนต์ serif (เช่น 402701), เส้นคั่นล่าง แล้วมีแถวเล็ก "งวดถัดไป 16 ต.ค." กับลิงก์ "เอกสารทางการ (PDF)"
- **คอลัมน์ขวา (รางวัลเลขท้าย / เลขหน้า):** หัวเล็กตัวพิมพ์ใหญ่สีเทา แล้วเป็นแถวรางวัล 3 แถว (เลขท้าย 2 ตัว / เลขหน้า 3 ตัว / เลขท้าย 3 ตัว) แต่ละแถวมีเส้นคั่นบาง ชื่อรางวัลซ้าย เลขใหญ่ด้วย serif ด้านขวา — คู่เลข 3 ตัว (เช่น 791 · 912) แสดงเคียงกัน
- คงข้อความตรวจสอบ "ยืนยันตรงกัน 2 แหล่ง" / ลิงก์เอกสารทางการในหมายเหตุใต้หัวข้อตามเดิม (แหล่งข้อมูลจริง ไม่เปลี่ยน)

## ไฟล์ที่แก้
1. `src/components/weekly-comparison.tsx` — ลบ arrivals + ผังใหม่
2. `src/components/metric-signal-chart.tsx`, `cost-signal-chart.tsx`, `rail-signal-chart.tsx` — ลบการป้อน arrivals
3. `src/components/signals-ui.tsx` — ลบ SignalDates และการเรียกใช้
4. `src/components/latest-lottery.tsx` — ผังสองคอลัมน์แบบ v1
