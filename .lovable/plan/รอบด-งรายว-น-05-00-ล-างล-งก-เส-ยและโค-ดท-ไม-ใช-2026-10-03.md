# รอบดึงรายวัน 05:00 + ล้างลิงก์เสียและโค้ดที่ไม่ใช้

## 1. RakaKaset, ExchangeRate, สมาคมค้าทองคำ ดึง "รายวัน ทุกวัน 05:00"
- ตอนนี้: ทองและอัตราแลกเปลี่ยนถูกดึงทุกชั่วโมงไปพร้อมแหล่งอื่น ส่วน RakaKaset ถูกดึงในรอบรายวัน/รอบบังคับ หรือเมื่อยังไม่มีราคาอาหารของวันนี้
- ใหม่: ทั้ง 3 แหล่งดึงเฉพาะรอบ 05:00 น. (เวลากรุงเทพ) ทุกวัน รวมเสาร์-อาทิตย์ รอบ 05:30 ดึงซ้ำเฉพาะแหล่งที่รอบ 05:00 ล้ม ไม่ถูกดึงในรอบรายชั่วโมงอีก ยังกดดึงเองได้จากหน้าตั้งค่า
- หน้าแหล่งข้อมูล / ติดตามข้อมูล แสดงรอบอัปเดตเป็น "รายวัน ทุกวัน 05:00" และถือว่าข้อมูลเก่าเกินถ้าเกิน 1 วัน
- ค่าที่ได้ตอน 05:00 ยังทันเวลาตัด 05:45 ของ Daily Brief

## 2. ตรวจลิงก์เสียและลิงก์ที่ไม่ได้ใช้ แล้วล้างให้หมด
- ไล่เปิดทุกหน้าในเว็บด้วยเบราว์เซอร์ทดสอบ เก็บลิงก์ภายในทุกลิงก์ แล้วตรวจว่าเปิดได้ (ไม่ขึ้นหน้าไม่พบ)
- ตรวจลิงก์ภายนอก (ลิงก์แหล่งข้อมูล, ลิงก์หน่วยงาน, ลิงก์ในหน้า method/sources) ว่าตอบได้จริง ลิงก์ที่ตายถาวรจะลบหรือเปลี่ยนเป็นลิงก์ที่ใช้ได้ของหน่วยงานเดียวกัน
- ลบส่วนที่ไม่มีอะไรใช้แล้ว เช่น ตารางเก่าของแค็ตตาล็อกข้อมูลเปิดภาครัฐที่ยกเลิกไปแล้ว (เก็บโครงไว้แต่ทำเครื่องหมายว่าเลิกใช้), แหล่งที่ไม่ได้ดึงแล้วแต่ยังค้างในทะเบียน/ประวัติการดึง, ไฟล์/ฟังก์ชัน/component ที่ไม่มีใครเรียก
- จะสรุปรายการที่พบและสิ่งที่ลบ/แก้ทุกข้อให้ดู

## รายละเอียดทางเทคนิค
- `ingest.server.ts`: แยกชุด `DAILY_05` = connectors "สมาคมค้าทองคำ", "ExchangeRate (อัตราแลกเปลี่ยน)" + job rakakaset; ตัดออกจากรอบ hourly/early อื่น; เพิ่มใน `?mode=early` เมื่อชั่วโมงกรุงเทพ = 5 และใน 05:30 daily เฉพาะที่ `source_runs.ok=false` หรือยังไม่มีค่าวันนี้; manual ยังรวม
- RakaKaset แยกจากเงื่อนไข checkraka (CheckRaka คงเดิม)
- `source_registry`: cadence = 'รายวัน ทุกวัน 05:00', stale_after_days = 1 สำหรับ 3 แหล่ง (run_sql)
- ลิงก์: สคริปต์ Playwright ไล่ทุก route จาก sitemap + route ที่ไม่ได้อยู่ใน sitemap, เก็บ `a[href]`, ตรวจ internal ด้วย HTTP status/หน้า 404 และ external ด้วย HEAD/GET timeout 20s
- โค้ด: หาไฟล์/export ที่ไม่มีการ import (rg + tsgo), ลบ; ตาราง gov_datasets/gov_snapshots/gov_changes ใส่ COMMENT 'DEPRECATED' (ห้าม drop โดยไม่ขออนุญาต) และลบแถวค้าง; ลบแถว source_runs/source_run_history ของแหล่งที่ยกเลิกแล้ว
- อัปเดต AGENTS.md ข้อ Ingest และ src/lib/AGENTS.md
