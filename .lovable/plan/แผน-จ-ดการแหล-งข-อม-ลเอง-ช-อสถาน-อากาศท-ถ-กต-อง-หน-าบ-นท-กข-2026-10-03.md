# แผน: จัดการแหล่งข้อมูลเอง, ชื่อสถานีอากาศที่ถูกต้อง, หน้าบันทึกข้อมูลดิบ

## 1. หน้าจัดการแหล่งข้อมูลสำหรับผู้ดูแล (ใน /settings)
แหล่งข้อมูลแต่ละแห่ง (กรมอุตุฯ, GISTDA, กรมชลฯ, ThaiWater, Longdo, ราคาทอง, ค่าเงิน, CheckRaka/RakaKaset, สลาก, FM91) มีแถวที่ตั้งค่าได้ดังนี้:
- **เปิด/ปิด** การดึงข้อมูล
- **ช่วงเวลาอัปเดต**: ทุกชั่วโมง / ทุก 3 ชั่วโมง / วันละครั้ง (เลือกเวลาได้) / ดึงด้วยมือเท่านั้น
- **วิธีส่งคำขอ**: อัตโนมัติ / ตรง / ผ่าน Firecrawl (ตอนนี้ตั้งได้แค่ Longdo กับ ThaiWater จะเปิดให้ตั้งได้ทุกแหล่ง)
- **จำนวนครั้งที่ลองใหม่** และ **ระยะรอก่อนลองใหม่**
- ปุ่ม **"ดึงตอนนี้"** พร้อมผลล่าสุด (สำเร็จ/ล้มเหลว, เวลา, จำนวนแถว)

ถ้าไม่ได้ตั้งค่าอะไร ทุกแหล่งจะทำงานตามรอบเดิม (กำหนดเวลาทำสรุปข่าว 05:45/05:55 ไม่เปลี่ยน) ผู้ดูแลเท่านั้นที่แก้ค่าได้

## 2. สถานีอากาศในกรุงเทพฯ ที่มีข้อมูลจริง
ข้อมูลรอบล่าสุด (3 ต.ค.) มีค่าจริงจาก 5 สถานีรายงานทุก 3 ชั่วโมง: กรุงเทพมหานคร (48455), ท่าเรือคลองเตย (48454), บางนา สกษ. (48453), ดอนเมือง (48456), สุวรรณภูมิ (48429)
- ตรวจย้อนหลังว่าแต่ละสถานีส่งค่าอุณหภูมิ/ฝนครบแค่ไหน
- หน้าแหล่งข้อมูลจะแสดงชื่อและรหัสของสถานีที่ใช้ค่าจริงในวันนั้น (เช่น "กรุงเทพมหานคร 48455" หรือสถานีสำรองที่ใช้แทน) ไม่ใช้ชื่อกว้าง ๆ แบบ "BANGKOK METROPOLIS"
- เพิ่มบรรทัด "ใช้แทน: <สถานี> เพราะสถานีหลักไม่มีข้อมูล" เมื่อมีการสลับสถานี

## 3. หน้าบันทึกข้อมูลดิบ (ใหม่: /raw-log สำหรับผู้ดูแล)
ตารางเรียงเวลา แต่ละแถวคือการดึงข้อมูลหนึ่งครั้ง:
- แหล่ง / หน่วยงาน, ที่อยู่ลิงก์ต้นทาง, เวลาดึงครั้งแรก, เวลาเห็นล่าสุด, จำนวนครั้งที่เห็นไฟล์เดิม
- สถานะการตอบกลับ, ขนาดไฟล์, ไฟล์เปลี่ยนหรือเหมือนเดิม
- ค่าที่อ่านได้จากไฟล์นั้น (เช่น ระดับน้ำ, ฝน, อุณหภูมิ, ปริมาณน้ำในเขื่อน)
- ตัวกรอง: หมวด (อากาศ, น้ำ/เขื่อน, น้ำท่วม, ฝุ่น, ราคา), แหล่ง, ช่วงวันที่
- ปุ่มเปิดไฟล์ดิบและเทียบกับไฟล์ก่อนหน้า (ใช้ระบบเดิมของหน้าหลักฐาน)

หมายเหตุ: ตอนนี้ยังไม่มีแหล่งข้อมูล "น้ำท่วม" หรือ "น้ำในท้องถิ่น" เข้ามาในระบบ หน้านี้จะแสดงเฉพาะแหล่งที่เปิดใช้งานจริง (กรมชลฯ เขื่อน, ThaiWater เจ้าพระยา C.13) ถ้าต้องการเพิ่มแหล่งใหม่ ต้องแจ้งชื่อแหล่ง/ลิงก์ที่ต้องการ

## รายละเอียดทางเทคนิค
- เพิ่มตาราง `source_config` (source PK, enabled, schedule kind/hour, fetch_mode, max_attempts, retry_delay_min, updated_at) พร้อม GRANT, RLS: anon อ่านไม่ได้, admin อ่าน/เขียนผ่าน `has_role`
- `queue.server.ts`/cron ingest อ่าน `source_config` ก่อน enqueue; ไม่มีแถว = พฤติกรรมเดิม; ย้ายค่า `longdo_mode`/`thaiwater_mode` เข้ามา (อ่านค่าเก่าเป็น fallback)
- server function `saveSourceConfig`, `runSourceNow` ใช้ `requireAdmin`
- `tmd3h.ts` บันทึกสถานีที่ใช้จริงลง `source_runs.sample` / `weather_station_obs`; หน้า sources อ่านชื่อจากตรงนั้น
- `/raw-log` อยู่ใต้ `_admin` อ่าน `raw_evidence` join `observations.evidence_id` (และ `dam_readings`) แบบแบ่งหน้า; ลิงก์ไฟล์ใช้ `evidenceUrl`/`evidenceDiff` เดิม
- อัปเดต AGENTS.md สำหรับโครงสร้างใหม่
