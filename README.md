# Thailand Daily Signals

อยากพัฒนาแพลตฟอร์ม Thailand Daily Signals ที่ตอบคำถามเดียวว่า: “วันนี้ มีอะไรเปลี่ยนไปในประเทศไทยที่อาจกระทบชีวิตฉัน?” จุดสำคัญคือไม่ใช่ทุกข้อมูลต้อง real-time และไม่ควรเอา GDP มาแสดงทุกวันทั้งที่เลขไม่เปลี่ยน ระบบควรเป็น change-driven / event-driven: อะไรไม่เปลี่ยนก็เงียบ อะไรเปลี่ยนอย่างมีนัยสำคัญค่อยกลายเป็น Signal  โดยดึงข้อมูลจากหน่วยงานราชการหลายหน่วยงานมี API / Open Data / RSS หรือหน้าเว็บที่อัปเดตเป็นระบบ
